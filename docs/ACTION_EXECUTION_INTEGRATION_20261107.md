# 11/7 整合進度：場所行動正式交易（尚非全系統完成）

## 版本基準

基於 `discord-rp-bot-main(20261107-045041).zip`；**不覆蓋**新醫院與排行榜修正。

## 本次完成

- `/行動` 已核准行動可選擇本人已啟用角色，再按「確認執行」。
- 在單一 SQLite `BEGIN IMMEDIATE` 交易中確認角色歸屬及啟用狀態、扣付費行動值、金幣支出或薪資、發放合法屬性／技能及三種點數獎勵。
- 使用獨立請求鍵和指紋防重複結算，扣款或發獎中途出錯自動回滾。
- 工作薪資由 `system/location_actions` 流入角色錢包；活動／課程費用轉回系統金庫。
- 行動值不會拿 `characters.stamina` 取代。已核准項目執行時，消耗商城已有的**付費行動值**，先扣最早到期的包。
- 原本 266 項普通行動全部保持 **待審核**，不會因程式存在而自動開放。
- 醫院的治療及小／大整形維持群主私密預覽，不會擅自計費、擲骰或加點；不新增孕產服務。
